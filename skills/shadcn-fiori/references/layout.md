# Layout

## dynamic-page

Fiori dynamic page: sticky title (heading, breadcrumbs, KPIs, actions), header that snaps on scroll, expand/collapse and pin buttons, floating footer.

Usage guidance has not been authored for this item yet; inspect its installed API before choosing it.

Main exports: `DynamicPage`, `DynamicPageHeader`, `DynamicPageTitle`, `defaultDynamicPageTexts`.

```bash
npx shadcn add @fiori/dynamic-page
```

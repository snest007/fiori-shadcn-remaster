# Dates

## calendar

Fiori calendar: day / month / year / year-range pickers, single, multiple or range selection, week numbers, special days and legend, the SAP keyboard model. Gregorian, Intl-based.

Usage guidance has not been authored for this item yet; inspect its installed API before choosing it.

Main exports: `Calendar`, `CalendarLegend`, `CalendarLegendItem`.

```bash
npx shadcn add @fiori/calendar
```

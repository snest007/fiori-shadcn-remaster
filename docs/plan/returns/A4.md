# A4 return (after 2 reviews) — fix only this, branch codex/A4 (worktree .worktrees/A4)

Verified by Claude against UI5 2.28 source. Add a regression test.

**Shift+Space must not activate the overflow button.** UI5 `Button.js` `_onkeydown`: Shift (or Escape) sets
`_cancelAction`; `_onkeyup`: on Space/Shift+Space with `_cancelAction` it `preventDefault()`s and returns — no click.
Ours activates the default and the custom "+N" overflow button and fires `onOverflowClick` (`registry/ui/avatar.tsx:416,426`).
Port that cancel logic for the overflow button (both default and custom), and for the group-type root if it uses the
same Space handling. Escape during a held Space must cancel too.

Tests (tests/avatar.spec.ts): Shift+Space and Space-then-Escape on the default and the custom overflow button fire nothing;
plain Space and Enter still fire `onOverflowClick` once.

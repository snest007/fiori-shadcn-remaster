# petalo

React 19 components that follow the SAP Fiori Horizon design language in appearance and interaction, delivered as a shadcn registry. Theme values and icons come from SAP's open-source packages (the 72 font is an optional, separately licensed item); the components are compared against UI5 Web Components 2.28.

## Install the registry

Start with a React 19 app using Tailwind CSS v4:

```sh
npx shadcn@latest init https://snest007.github.io/petalo/r/petalo.json
npx shadcn add @petalo/button
```

## Explore a component

Select a component in the sidebar. Playground provides live Controls; each variant has its own story and **Show code**. The Docs page includes the install command, props, and usage guidance where available.

Use **Theme** in the toolbar to choose Morning Horizon, Evening Horizon, High Contrast Black or High Contrast White. **Density** switches cozy and compact layouts. **Direction** switches LTR and RTL. The settings apply to both the canvas and docs examples.

Set the same attributes on your application's `html` element:

```html
<html data-theme="sap_horizon_dark" data-density="compact" dir="rtl">
```
